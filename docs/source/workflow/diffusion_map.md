# Workflow: Diffusion map

## Purpose
Estimate spatially varying diffusion parameters by fitting local regions of the data.

## Steps
1. Open the **RICS Fitting** tab.
2. In the **Diffusion Map Fitting Parameters** section:
   - Select input file
   - Choose channel
   - Set window size and offset
3. Click **Generate Diffusion Map**.

## Outputs
Typical outputs include:
- A diffusion map array (D map)
- Auxiliary arrays (brightness/number maps if computed)
- An auxiliary NPZ with intermediate results
